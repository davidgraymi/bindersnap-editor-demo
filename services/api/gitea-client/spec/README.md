# Gitea Spec

## gitea.d.ts

Auto-generated by `bun run generate:gitea-client`, which reads `swagger.v1.json`
off a running Gitea. The first line of `gitea.d.ts` names the Gitea version it
was generated from. Never edit it, or `openapi3.json`, by hand: CI regenerates
both offline from `swagger2.json` and `extensions.json` and fails on any
difference.

Regenerate after every Gitea upgrade: `bun run up`, then
`GITEA_URL=<the gitea URL from bun run stack status> bun run generate:gitea-client`.
The script rewrites all three files here — `swagger2.json` (fetched as-is),
`openapi3.json` (converted, then patched with `extensions.json`) and
`gitea.d.ts` — so commit them together.

## extensions.json

Maintained by Bindersnap. Used to extend the openapi spec with additional
information. Typically used for adding enumerations to `string` types.

To pick up a change to this file without replacing the committed spec:

```bash
bun run scripts/generate-gitea-api.ts --offline
```

That re-runs the conversion, the merge and the typegen against the
`swagger2.json` already here and fetches nothing.
