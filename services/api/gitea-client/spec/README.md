# Gitea Spec

## gitea.d.ts

Auto-generated by `bun run generate:gitea-client`, which reads `swagger.v1.json`
off a running Gitea. The committed types were generated from 1.27.3, the version
both stacks run.

Regenerate after every Gitea upgrade: `bun run up`, then
`bun run generate:gitea-client`. The script rewrites all three files here —
`swagger2.json` (fetched as-is), `openapi3.json` (converted, then patched with
`extensions.json`) and `gitea.d.ts` — so commit them together.

## extensions.json

Maintained by Bindersnap. Used to extend the openapi spec with additional information. Typically used for adding enumerations to `string` types.
